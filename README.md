## Information

This is a very simple project that follows very closely the [**Ray Tracing in One Weekend**](https://github.com/RayTracing/) tutorial to gain insight into graphic programming.
My ultimate goal is to be able to apply what I learned in school with Nvidia Cuda and greatly speed up the rendering process.

My current Nvidia Cuda (in-progress) version of this project is located [**Here**](https://github.com/Enza514/build-a-ray-tracer-cuda-version).
